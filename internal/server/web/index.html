Accepted columns

      
Required: amount, csp_id. Recommended: txn_id, timestamp (or date + time), txn_type, from_account, to_account, ko_id, customer_charge, channel (ONUS/OFFUS), status, peer_group (region/district). Aliases such as “From Account”, “Debit A/c”, “Agent ID”, “Txn Date” work too.
